🤖 مقدمة عن ROS

ما هو نظام ROS؟

نظام تشغيل مفتوح المصدر مصمم خصيصاً لتطبيقات الروبوتات. يوفر أدوات وحزم برمجية شاملة تسهل تطوير وتشغيل الروبوتات المعقدة.

✨ المميزات الأساسية:
  • تواصل فعال وموثوق بين مكونات الروبوت
  • مكتبات شاملة للتحكم والاستشعار
  • محاكاة ثلاثية الأبعاد (Gazebo)
  • أدوات تصور البيانات (RViz)
  • مدعوم من قبل مجتمع عالمي ضخم

🐧 أوامر Linux الأساسية

هذه الأوامر ضرورية جداً قبل البدء مع ROS:

الأمر الشرح مثال
ls عرض محتويات المجلد $ ls -la
cd الانتقال إلى مجلد $ cd Desktop
pwd عرض المسار الحالي $ pwd
mkdir إنشاء مجلد جديد $ mkdir robot
sudo تنفيذ كمسؤول $ sudo apt-get update
apt-get install تثبيت حزمة $ sudo apt-get install ros-humble

🔧 تثبيت ROS 1 - Noetic

⚠️ متطلبات التثبيت: Ubuntu 20.04 LTS

الخطوة 1️⃣: تفعيل أكواد المستودع

sudo sh -c 'echo "deb http://packages.ros.org/ros/ubuntu $(lsb_release -sc) main" > /etc/apt/sources.list.d/ros-latest.list'

الخطوة 2️⃣: إضافة المفتاح الأمني

sudo apt install curl && curl -s https://raw.githubusercontent.com/ros/rosdistro/master/ros.key | sudo apt-key add -

الخطوة 3️⃣: تحديث قائمة الحزم

sudo apt update

الخطوة 4️⃣: تثبيت ROS 1 Noetic

sudo apt install ros-noetic-desktop-full

الخطوة 5️⃣: إعداد البيئة

echo 'source /opt/ros/noetic/setup.bash' >> ~/.bashrc

الخطوة 6️⃣: تحميل الإعدادات

source ~/.bashrc

الخطوة 7️⃣: التحقق من التثبيت

roscore

إذا ظهرت رسالة البدء، التثبيت نجح! ✅

🔧 تثبيت ROS 2 - Humble

⚠️ متطلبات التثبيت: Ubuntu 22.04 LTS أو أحدث

الخطوة 1️⃣: تحديث النظام

sudo apt update && sudo apt upgrade -y

الخطوة 2️⃣: تثبيت البرامج المساعدة

sudo apt install software-properties-common curl -y

الخطوة 3️⃣: إضافة المفتاح

sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg

الخطوة 4️⃣: إضافة المستودع

echo "deb [arch=amd64 signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu jammy main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

الخطوة 5️⃣: تحديث الحزم

sudo apt update

الخطوة 6️⃣: تثبيت ROS 2 Humble

sudo apt install ros-humble-desktop -y

الخطوة 7️⃣: إعداد البيئة

echo 'source /opt/ros/humble/setup.bash' >> ~/.bashrc

الخطوة 8️⃣: تحميل الإعدادات

source ~/.bashrc

الخطوة 9️⃣: التحقق من التثبيت

ros2 --version

📝 أهم أوامر ROS 1

الأمر الشرح
roscore تشغيل خادم ROS الرئيسي (يجب تشغيله أولاً)
rosnode list عرض قائمة جميع العقد النشطة
rostopic list عرض قائمة المواضيع المتاحة
rosservice list عرض قائمة الخدمات المتاحة
rostopic echo [topic_name] عرض البيانات المرسلة عبر موضوع
rosmsg show [msg_type] عرض هيكل الرسالة وحقولها
roslaunch [pkg] [file] تشغيل ملف إطلاق بسهولة
rosrun [pkg] [node] تشغيل عقدة محددة
rosparam set [param] [value] تعيين قيمة معامل
rosparam get [param] الحصول على قيمة معامل

📝 أهم أوامر ROS 2

الأمر الشرح
ros2 node list عرض قائمة العقد النشطة
ros2 topic list عرض قائمة المواضيع المتاحة
ros2 service list عرض قائمة الخدمات المتاحة
ros2 topic echo [topic] عرض البيانات المرسلة عبر موضوع
ros2 interface show [msg] عرض هيكل الرسالة
ros2 launch [pkg] [file] تشغيل ملف إطلاق
ros2 run [pkg] [exe] تشغيل عقدة أو برنامج
ros2 param list عرض قائمة المعاملات
ros2 param set [node] [param] [value] تعيين قيمة معامل
ros2 param get [node] [param] الحصول على قيمة معامل
ros2 node info [node] الحصول على معلومات عقدة
ros2 topic info [topic] الحصول على معلومات موضوع

📊 مقارنة ROS 1 و ROS 2

🔴 ROS 1 (Noetic)

  • Ubuntu 20.04 LTS
  • بروتوكول TCP/IP
  • أداء جيد
  • أمان محدود
  • دعم Python 2/3
  • مستقر وموثوق
  • حزم كثيرة متاحة

🟢 ROS 2 (Humble)

  • Ubuntu 22.04 / 24.04
  • بروتوكول DDS
  • أداء أفضل وأسرع
  • أمان قوي جداً
  • Python 3 فقط
  • حديث وآمن
  • المستقبل
💡 الخلاصة:

استخدم ROS 1 للمشاريع القديمة والتعلم الأساسي، واستخدم ROS 2 للمشاريع الجديدة والعملية.

💡 نصائح مهمة للعمل مع ROS

  • استخدم rqt_graph في ROS 1 لتصور تدفق البيانات بين العقد
  • استخدم ros2 topic hz لقياس تردد نشر الموضوع
  • تأكد من تحميل setup.bash قبل استخدام أي أوامر ROS
  • استخدم launch files لتشغيل عدة عقد في نفس الوقت
  • احفظ أكوادك في workspace منظم
  • استخدم rosbag لتسجيل البيانات وإعادة تشغيلها
  • اقرأ رسائل الخطأ بعناية - فهي تخبرك بالمشكلة
  • قم بعمل backup منتظم لملفات المشروع المهمة
